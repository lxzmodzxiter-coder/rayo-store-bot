# ⚡ RAYO FIX STORE

Bot de Telegram desarrollado en **Python** con **aiogram 3.x**, diseñado para ofrecer una experiencia rápida, moderna y estable.

## 🚀 Características

- 🛍️ Catálogo de productos
- 👤 Registro automático de usuarios
- 💰 Sistema de saldo
- 🛒 Compras automáticas
- 🎟️ Sistema de cupones
- 💎 Membresía Premium
- 📦 Historial de compras
- 👑 Panel Owner
- ⚙️ Panel Admin
- 📊 Estadísticas
- 📢 Difusión de mensajes
- 💾 Base de datos SQLite
- 🌐 Compatible con Render y GitHub
